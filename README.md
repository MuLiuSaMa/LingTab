# LingTab

一个简洁美观的 Chrome 新标签页扩展。

## 特性

- **搜索** - 集成 Bing 搜索，带搜索建议下拉框
- **时钟** - 数字/钟表两种样式，支持自定义颜色、大小、位置、拖拽
- **Dock 栏** - 快速访问常用网站，支持手动添加、右键删除
- **背景** - 每日 Bing 壁纸自动更新
- **主题色** - 自定义主题色，沉浸式体验
- **液态玻璃** - 毛玻璃 + 液态玻璃滤镜 UI 风格

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目文件夹

## 开发

```
git clone https://github.com/MuLiuSaMa/lingtab.git
```

直接修改 `LingTab/` 目录下的文件，刷新扩展即可预览。
